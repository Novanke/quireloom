# Novanke/quireloom

Pure MoonBit booklet imposition, source-page provenance and print-job validation.

Version 0.2.0 adds selected page ranges, chapter assembly, balanced or mixed-size
gatherings, calibrated manual duplex schedules, preflight, source-labelled JSON
and CSV, SVG proof atlases and a command-line adapter.

Start with [README](https://github.com/Novanke/quireloom/blob/main/README.md),
[the job format](https://github.com/Novanke/quireloom/blob/main/docs/job-format.md),
and [the example job](https://github.com/Novanke/quireloom/blob/main/examples/workbook.json).

AI assisted implementation and technical documentation. Source artwork/PDF parsing
and printer-driver control are outside the scope. Manual refeed order requires a
physical calibration. Competition acceptance is determined by the organizer.
